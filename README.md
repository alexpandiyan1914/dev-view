# Dev View

A clear view of your project.

Dev View is a CLI that inspects a project, finds problems, explains why they
matter, and suggests how to fix them.

## Status

Early development (v0.1.0). Not published yet.

## Installation

```bash
git clone https://github.com/alexpandiyan1914/dev-view.git
cd dev-view
npm install
npm run build
npm link
```

## Usage

```bash
dev-view local
```
